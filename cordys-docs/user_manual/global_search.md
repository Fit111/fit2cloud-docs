---
title: 全局搜索
description: 介绍 Cordys CRM 全局搜索的入口位置、检索范围与结果查看方式。
---

全局搜索是 Cordys CRM 的统一检索入口，用于在系统中快速定位线索、客户、商机等业务数据。无需依次进入各业务模块，只需在顶栏输入一个关键词即可跨模块取数，适合客户来电、会议沟通等需要即时调取资料的场景。

## 1 功能简介

全局搜索以顶栏搜索框为唯一入口，按**业务对象分类**组织检索结果。输入关键词并执行搜索后，面板顶部会按类别给出命中数量，例如「客户 (79)」「商机 (80)」「联系人 (78)」，切换页签即可只看某一类结果。

检索范围覆盖 **线索、线索池、客户、公海、商机、联系人** 六类数据；结果列表按当前选中类别展示对应字段，以客户为例：公司名称、负责人、部门、意向产品、联系人电话、最新跟进时间。列表底部显示本次命中的总条数，数据量较大时可点击「回到顶部」快速返回列表顶部。

## 2 入口位置

在系统顶栏点击搜索图标，页面右侧打开「搜索」面板。

面板输入框提示「请输入客户名或手机号」，输入关键词后回车或点击输入框右侧的搜索按钮即可发起检索。

## 3 结果查看

搜索结果按类别分页签展示，各页签后的括号数字表示该类别下的命中数量。

<img style={{display:"block",margin:"16px auto",maxWidth:"100%"}} src="/img/cordys/user_manual/global-search-result.png" alt="图 2  搜索结果与分类页签" />

<div style={{textAlign:"center",color:"#8a8f99",fontSize:"13px",margin:"6px 0 20px"}}>图 2  搜索结果与分类页签</div>

检索结果的处理方式如下：

- **切换类别**：点击面板顶部的类别页签，即可在「线索 / 线索池 / 客户 / 公海 / 商机 / 联系人」之间切换，只看当前类别的命中记录。
- **查看字段**：不同类别展示的字段不同。客户类别展示公司名称、负责人、部门、意向产品、联系人电话、最新跟进时间，点击记录名称可直接进入对应详情页。
- **空结果**：当前类别无匹配数据时，列表区显示「暂无数据」，底部条数显示为 0。

:::note[说明]
搜索面板会保留所有类别页签；未命中的类别同样展示页签并将数量标为 0，便于确认该类数据确实没有匹配项。
:::
