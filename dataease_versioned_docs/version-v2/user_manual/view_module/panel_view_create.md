title: 添加图表
---

## 1 新建图表

:::note

进入数据大屏编辑界面，页面顶部菜单点击【图表】。
:::

![添加视图](/img/dataease-v2/view_generation/2.0数据大屏点击图表组件.png)

:::note

选择一个图表类型后，点击进入下一步.
:::

![添加视图](/img/dataease-v2/view_generation/2.0数据大屏选择图表.png)

:::note

选择一个数据集（支持搜索）。
:::
![添加视图](/img/dataease-v2/view_generation/2.0数据大屏搜索选择数据集.png)

:::note

将字段拖到维度框与指标框，点击【更新图表数据】，新建图表完成。
:::

![添加视图](/img/dataease-v2/view_generation/2.0数据大屏数据设计.png)

![添加视图](/img/dataease-v2/view_generation/2.0数据大屏图表效果.png)

## 2 更换图表
:::note

支持在数据大屏中切换图表类型，将已存在图表切换成其他图表类型。
:::

![更新1](/img/dataease-v2/view_generation/数据大屏支持切换图表类型.png)
