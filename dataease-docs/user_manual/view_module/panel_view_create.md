---
title: 添加图表
---

## 1 新建图表

:::note

进入数据大屏编辑界面，页面顶部菜单点击【图表】。
:::

![添加视图](/img/dataease/view_generation/数据大屏点击图表组件.png)

图 1  选择图表组件

:::note

选择一个图表类型后，点击进入下一步.
:::

![添加视图](/img/dataease/view_generation/数据大屏选择图表.png)

图 2  数据大屏选择图表

:::note

选择一个数据集（支持搜索）。
:::

![添加视图](/img/dataease/view_generation/数据大屏搜索选择数据集.png)

图 3  数据大屏搜索选择数据集

:::note

将字段拖到维度框与指标框，点击【更新图表数据】，新建图表完成。
:::

![添加视图](/img/dataease/view_generation/数据大屏数据设计.png)

图 4  数据大屏数据设计

## 2 更换图表

:::note

支持在数据大屏中切换图表类型，将已存在图表切换成其他图表类型。
:::

![数据大屏切换图表类型](/img/dataease/view_generation/数据大屏支持切换图表类型.png)

图 5  数据大屏切换图表类型
