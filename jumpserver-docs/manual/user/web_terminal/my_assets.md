## 1 资产树

Web 终端左侧的 **我的资产** 展示当前组织下已授权给当前用户的资产。展开资产节点可查看可访问的资产，单击资产即可在右侧加载连接配置。

如果资产树为空，请确认 **管理员** 是否已为该用户配置好资产授权。

## 2 组织切换

当用户在多个组织中均拥有资产授权时，可单击左上角的 **切换组织** 按钮切换当前组织，资产树会同步刷新为该组织下的授权资产。

## 3 资产搜索

顶部 **搜索** 框支持按资产名称或 IP 进行模糊匹配，输入关键字即可快速定位目标资产。

## 4 我的收藏

**我的收藏** 用于集中展示用户标记为收藏的资产，便于高频资产快速访问。

设置收藏的两种方式：

- 在 Web 终端左侧列表中右键目标资产，选择收藏。
- 在工作台的资产连接页面进行设置。

## 5 资产操作

- **左键单击**：在页面右侧加载该资产的连接配置，可继续选择协议、账号和连接方式。
- **右键单击**：弹出操作菜单，可重新选择连接方式与账号、加入收藏等。
- **勾选资产**：勾选后可对选中资产批量发起连接，详见 [连接资产](assets_connect.md)。

## 6 服务器状态与文件

连接资产后，可查看当前连接服务器的资源占用情况，并进行文件传输操作。相关操作说明请参考 [文件管理](../workbench/my_assets/file_explorer.md)。
