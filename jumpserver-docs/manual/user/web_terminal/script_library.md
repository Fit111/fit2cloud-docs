## 1 功能简介

脚本库用于编辑和存放常用的脚本，方便在资产上执行某些操作，减少重复输入命令。脚本库入口位于 Web 终端左侧列表中。

## 2 前提条件

- 已登录 JumpServer 并进入 Web 终端页面。
- 当前用户已被授权目标资产。
- 脚本库中已存在可用的脚本，脚本由管理员或当前用户在 **工作台 > 作业中心 > 模版管理** 中创建。

## 3 执行脚本

1. 在 Web 终端左侧列表中选择 **脚本库**。
2. 展开脚本列表，选择需要执行的脚本并查看脚本内容。
3. 选择脚本要执行的资产范围。
4. 单击执行，在输出区域查看执行结果。

## 4 脚本的维护

脚本库中的脚本来源于 **模版管理**，可按照用途维护为 **公有** 或 **私有** 范围：公有脚本对用户可见，私有脚本仅创建者可见。

脚本模板的创建与字段说明请参考 [模板管理](../workbench/job_center/templates_management.md)。
