## 1 功能简介

Web 终端（Luna）用于在浏览器中连接已授权的资产，无需安装任何插件。单击工作台中的 Web 终端入口，或单击顶部导航栏的 Web 终端图标，均可跳转到 Web 终端页面。

Web 终端界面由左侧资产树、中间会话区和顶部工具栏组成：

- **左侧资产树**：展示当前组织下已授权给用户的资产，支持组织切换、搜索和收藏。详见 [我的资产](my_assets.md)。
- **中间会话区**：展示已建立的资产连接会话，支持拖拽、切换和分屏。详见 [连接资产](assets_connect.md)。
- **顶部工具栏**：提供文件管理、视图、语言、设置、帮助和窗口列表等功能。

界面说明：

1. **切换组织按钮** 点击可以切换当前组织
2. **搜索资产按钮** 可以输入对应资产名称快速筛选匹配资产，支持模糊匹配
3. **文件管理入口** 点击可以进入[文件管理](../workbench/my_assets/file_explorer.md)页面
4. **我的资产** 展开可以查看当前组织中获得 **授权** 使用的资产如果发现为空，请确认 **管理员** 是否配置好资产授权
5. **我的收藏** 可以查看自己设置为收藏的资产，设置方法为右键对应资产设置或者在工作台资产链接页面设置
6. **脚本库** 可以编辑一些常用的脚本存放在这，方便在资产上执行某些操作
7. **AI助手** 可以进行对资产状态的查询，可直接接手资产进行操作，需要管理员在 **系统设置** 中配置对应的智能体后使用
8. **服务器状态以及文件管理** 可以查看目前连接的服务器的资源占用情况以及进行文件传输

## 2 文件管理

在 Web 终端页面单击 **文件管理** 按钮，选择 **连接** 即可进入文件管理模块。文件管理模块的详细说明请参考 [文件管理](../workbench/my_assets/file_explorer.md)。

## 3 帮助

**帮助** 按钮分为文档、支持和下载三个模块。

- 文档与支持跳转链接可在 **系统设置 > 其它设置 > 导航栏链接** 中修改。
- 下载链接跳转至 JumpServer 系统周边工具下载页面，包含 JumpServer 客户端、微软 RDP 客户端、JumpServer 离线录像播放器等。

## 4 窗口列表

单击 **窗口列表** 按钮可查看当前正在连接的所有会话，并进行快速切换。
