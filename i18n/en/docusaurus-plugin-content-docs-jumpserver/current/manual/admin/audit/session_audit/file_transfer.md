## 1 Feature Overview

:::note

- Click the **Audit** button on the navigation bar to open the **Audit** page.
- Click **Session Audit &gt; File Transfer** to open the **File Transfer** page.
- File transfer allows you to view the history of all files uploaded to/downloaded from assets.
:::
