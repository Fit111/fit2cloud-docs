## 2 数据源管理

### 2.1 SQL Server低版本中文乱码如何解决

**问题**：SQL Server低版本数据源出现中文乱码，添加charset=GBK等配置无效怎么办？

**处理方式**：

SQL Server 数据源配置中提供“兼容低版本”选项。存量数据为保证可用性默认选中，新建时默认不选中。若连接失败或出现乱码，可尝试勾选该选项。注意：勾选“兼容低版本”后无法设置编码，若为 varchar 类型且排序规则为 Chinese_PRC，可在额外连接参数中添加 charset=GBK 解决乱码问题（nvarchar 类型通常不存在乱码）。

## 3 智能问答与助手

### 3.1 示例SQL因表召回限制未生效怎么办？

**问题**：编写了示例SQL，但因涉及表数量较多，部分表未被召回导致SQL执行失败，如何处理？

**处理方式**：

在【数据源】-【表关系】中维护相关表的关联关系，可避免白名单拦截导致的表召回丢失问题。

## 4 系统集成与权限

### 4.1 统一认证集成如何开启自动创建用户

**问题**：SQLBot 集成统一认证后，默认禁止自动创建用户，是否有开关可以开启该功能？

**处理方式**：

在「登录认证设置」中开启「第三方自动创建用户」开关即可。该设置用于控制外部系统（如平台对接、单点登录）接入 SQLBot 时是否自动创建用户账号。

详细配置步骤请参阅[参数配置](../enterprise/third-party-platform-settings.md)
